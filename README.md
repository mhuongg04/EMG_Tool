# EMG Tool - EMG Electromyography Disease Labeling Software

## How to run the code
1. Clone the frontend and backend repository (on this account)
2. Run "npm install"
3. For development: Run "npm run dev"
4. For product (Docker): Run "docker compose up --build -d" (cd to the docker/frontend-nginx (or docker/backend) to run this)

## Features
Labeling diseases on EMG Diagram, check and double check the data, export excel files
